# PS2 Supply
## Background
I had a friend ask about how to supply a PS2 from his car. Originally he wanted buy an inverter to run off an accessory port, then run the standard PS2 AC-DC adaptor. This is a workaround, that is (hopefully) significantly more efficient.

## Requirements
* Input Voltage: 6V - 18V (nominal)
* Input Voltage: 4V - 30V (transient)
* Output Voltage: 8.5V @ 1A (ish)
